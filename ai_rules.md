# AI agent rules

Project-specific rules for AI agents (Claude, Codex, etc.) working on this repo.

## Versioning

- Bump the version in `package.json` (and `CHANGELOG.md`) **at most once per
  calendar day**, even if multiple unrelated changes are made that day.
- If a version bump has already happened today, fold any further same-day
  changes into the existing `[Unreleased]`/current entry instead of bumping
  again.
- Only bump once per day even across multiple commits/PRs landing that day.
